# Scoring Rubric: OCEAN Traits (0-100) from Biography Text

Purpose: A non-specialist can rate the five OCEAN traits from a short biography text. Rate each 0-100 using the anchors. Paraphrase only from supplied text; do not infer from prior knowledge. If insufficient evidence, mark as "insufficient" and note why.

## Trait definitions (brief)
- Openness (O): Imagination, curiosity, novelty-seeking, aesthetic/ideas appreciation
- Conscientiousness (C): Organisation, self-discipline, reliability, goal-directed behaviour
- Extraversion (E): Sociability, assertiveness, energy from social interaction
- Agreeableness (A): Cooperation, empathy, trust, concern for others
- Neuroticism (N): Emotional sensitivity, tendency toward worry/negative affect (higher = more sensitive)

## Anchors
| Trait | 0-20 (low) | 40-60 (mid) | 80-100 (high) |
|---|---|---|---|
| O | Rigid, traditional, little curiosity | Some novelty-seeking, mixed interests | Inventive, curious, embraces new ideas/experiences |
| C | Disorganised, unreliable, procrastinates | Moderately organised, can be disciplined | Highly organised, diligent, meticulous, reliable |
| E | Reserved, shy, prefers solitude | Comfortable in groups, selectively outgoing | Sociable, energetic, assertive, draws energy from others |
| A | Competitive, suspicious, cold or harsh | Cooperative but can be firm | Warm, empathetic, trusting, concerned for others |
| N | Calm, even-tempered, resilient | Occasional worry/stress, manageable | Anxious, moody, easily stressed (high emotional sensitivity) |

## Instructions
1. Read the supplied biography text (description + Wikipedia summary) only.
2. For each trait, find concrete behaviours/choices/events that support your rating. Write one evidence line per trait.
3. Rate 0-100. If no concrete evidence, say "insufficient evidence" rather than guessing.
4. Be consistent: avoid clustering everything in 40-60 unless justified.
5. Record uncertainty (e.g., "confident" / "low confidence") if unsure.

## Calibration notes
Text-based scoring is inherently noisy; inter-rater agreement ~0.5 per trait is a reasonable target for this exercise (state in reporting). Weak traits should be displayed as bands and receive reduced matching weight if agreement is poor.
